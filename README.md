# fitnessPlus

A modern, premium redesign concept for [Fitness Plus](https://fitnessplus.club/), Gulshan, Dhaka.

**Live preview:** https://fitnessplus-redesign.vercel.app

## Stack

- **Next.js 16** (App Router, statically prerendered)
- **Tailwind CSS v4**
- **Motion** for animation
- `next/image` and `next/font` for fast loading

## Highlights

- Parallax hero with masked headline reveal and magnetic buttons
- Scroll-driven horizontal services gallery (desktop)
- Stacking sticky cards for the 4-step process
- Count-up stats, cursor-following spotlight on membership plans, scroll progress bar
- Hide-on-scroll glass navbar with an animated full-screen mobile menu
- WhatsApp lead form and floating chat button
- Fully responsive, and respects the reduced-motion setting

## Develop

```bash
npm install
npm run dev
```
