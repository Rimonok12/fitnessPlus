# fitnessPlus

A modern redesign concept for [Fitness Plus](https://fitnessplus.club/), Gulshan, Dhaka.

Static site (HTML, CSS, vanilla JS), no build step. Open `index.html` or deploy on Vercel.

**Live preview:** https://fitnessplus-redesign.vercel.app

- Dark, bold brand look in Fitness Plus black and red
- Fully responsive, with a mobile menu
- Scroll animations and stat count-ups
- WhatsApp lead form plus a floating chat button
- Sections: services, process, Fit Revolution, corporate wellness, success stories, membership, locations, contact

Design concept by Rimon Debnath. Not the official Fitness Plus website.
